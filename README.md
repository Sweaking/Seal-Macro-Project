# 🦭 Seal Macro

### A Macro For Tower Defense Simulator | Roblox

Seal Macro is a macro for Tower Defense Simulator

## Features

- **Visual Strategy Editor** build strategies right on a map screenshot, place pins, set the upgrade order, and time every ability per tower.
- **Maps & Strategies** multiple maps with importable, shareable strategies, plus a browser of community-made ones with ratings.
- **Smart Placements & Upgrades** drops towers and levels them in the exact order you set (two-path towers included) waiting on cash so nothing is wasted.
- **Support Tower Abilities** auto-fires Commander, DJ, Mercenary (airdrops + unit swaps), Medic, Hacker, Necromancer and Brawler, all timed by wave and cooldown.
- **Attack Type Switching** swaps Archer arrows and Trapper traps mid-match, and sets Mercenary and Kingpin units.
- **Timescale** activates 1.5x or 2x.
- **Modifiers & Gamemodes** auto-selects match modifiers and supports Survival, Hardcore and special modes.
- **Consumables & Skip Waves** drops consumables and skips waves exactly when you want.
- **Switch Targeting** switches tower targeting (First, Last, Strongest and more).
- **Tower Library** save a tower's placement and upgrade costs once, then reuse it across strategies.
- **Microing** hotkey helpers for playing by hand, spam upgrades and re-fire abilities on their cooldown.
- **Auto-Rejoin & Restart** keeps grinding through disconnects, losses, and match resets.
- **Discord Webhook** win/loss, stats, and screenshots sent straight to your server.
- **Reads the Game Live** watches the real wave and cash on screen instead of fragile fixed clicks.
- **Adapts Timing** adapts its timing to slower machines so placements still land.
- **Daily Logins & Playtime Rewards** claims your daily logins and playtime rewards automatically.

## Requirements

- **Windows 10 or 11**
- **Roblox on your main monitor at 1920x1080, fullscreen.** If your main monitor is a different resolution the detection will not line up.
- **Windows display scaling at 100%**
- Match your Roblox Graphics Quality and Text Size to the reference images on the macro's Dashboard & Tutorial

## Download

Get the latest build from the **[Releases](../../releases)** page just run the `.exe` file, no install needed.

**First launch:** the macro asks you to verify with Discord. Click the button, authorise, and access unlocks on its own. You need to be in the Discord server with the access role.

**Antivirus:** unsigned, so SmartScreen will warn on first run. VirusTotal scan for the current release https://www.virustotal.com/gui/file/d6cb5355eea9b77aa5b16502fc919ee52e7e7fb5c7a11fc88a1299b5f5df4b97
Two versions — same macro, same features. The only difference is file size and how antivirus reacts to it.

Seal Macro (Full) 460 MB Uncompressed, so antivirus is less likely to flag it (usually 1/68, just a generic Bkav hit).
Seal Macro (Compact) 140 MB Compressed to keep the download small. Antivirus sometimes adds a false "Wacatac" flag from the compression (usually 2/68) Same exact program
Both are unsigned, so Windows SmartScreen will warn on first launch either way → More info → Run anyway. Neither is "safer" than the other they're the identical macro. Pick whichever tradeoff you prefer smaller download, or a cleaner scan.
